# Ω-Math v1.0 — Implementation Roadmap

## Completed baseline

- v0.9 typed relational core;
- executable runtime;
- deterministic reference parser;
- conformance matrix;
- parser rejection rules;
- machine verification for experiments 010–012;
- canonical documentation boundary.

## v1.0 work packages

### P1 — Language surface

Expand the reference syntax without changing semantics. Add explicit declarations for transformations, observations, equivalence predicates, horizons and branching only where canonical signatures are already defined.

### P2 — Program model

Introduce a structured intermediate representation so parsing and execution are separate stages. Programs should be inspectable before execution.

### P3 — Research protocol

Represent hypothesis, null, model, intervention, observation, metric and criterion as explicit research metadata. Keep this layer outside primitive mathematical semantics.

### P4 — Verification engine

Provide deterministic validation of types, signatures, invalid states and declared experiment constraints. Add counterexample records for failed claims.

### P5 — Reproducibility

Record source version, parameters, seed/generation rule, environment metadata and result classification.

### P6 — Differential checks

Compare independent implementations or execution paths where feasible. A second implementation is evidence about implementation agreement, not proof of the mathematics.

### P7 — Research bridges

Define stable adapters for LAB and Graph. Do not add physical time, physical energy, probability or ontology to the core merely for integration convenience.

### P8 — v1.0 release gate

Release only when:

- language semantics and syntax are versioned;
- parser and runtime agree on every exposed operation;
- invalid programs are rejected deterministically;
- research records are reproducible;
- representative Ω hypotheses can be encoded;
- at least one deliberately false hypothesis produces a machine-detectable counterexample;
- canonical and historical documents are unambiguous.

## Explicit non-goals

Universal mathematics, automatic discovery of physical laws, unrestricted probability, physical time/energy primitives, and autonomous scientific interpretation are not v1.0 requirements.
