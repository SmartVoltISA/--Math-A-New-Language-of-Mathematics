# Ω-Math — Dynamic Response Invariant Audit v1.0

Date: 2026-09-09
Execution: local Python.

## Objective
Test whether the candidate nonreciprocity invariant survives when the observable is generated by a dynamical propagation model rather than directly by shortest paths.

## Model
- 20-node strongly connected directed weighted networks.
- Random directed edges plus a directed cycle for connectivity.
- Positive edge costs in [0.2, 2.0].
- Propagation response is generated by repeated linear spreading with kernel exp(-cost).
- Directionality is measured from the source-target response matrix using normalized absolute asymmetry.
- 30 independent seeds.

## Result
Directed dynamic models produced nonzero normalized response asymmetry in all 30/30 realizations.
Observed mean over realizations: 0.2285866; range: 0.1634183–0.3717990.

A symmetric-weight control also produced a small nonzero response statistic (10/10), showing that the raw statistic is not a universal discriminator of directed dynamics by itself. Control values were approximately 0.0316–0.0531.

## Critical finding
The candidate survives transfer from shortest-path construction to a dynamic response construction, but the symmetric control exposes an important limitation: response asymmetry can be generated by the propagation/normalization procedure even when the underlying edge costs are symmetric.

Therefore the invariant must not be promoted merely because it is nonzero. A valid foundational discriminator must separate intrinsic relational nonreciprocity from asymmetry introduced by the observation/dynamics operator.

## Verdict
**NOT FOUNDATIONAL.**

The current evidence supports only the existence of a label-independent normalized asymmetry observable. It does not yet establish that the observable is an intrinsic property of the relational structure independently of the chosen response operator.

## Required next gate
Construct paired systems with exactly the same observation operator and matched symmetric/nonreciprocal relational structures, then require the statistic to distinguish them with preregistered null controls. Repeat across multiple operators. Promotion requires operator-robust discrimination, not merely operator-dependent nonzero signal.
