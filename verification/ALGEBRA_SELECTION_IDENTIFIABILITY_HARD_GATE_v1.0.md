# Ω-Math — Algebra Selection / Identifiability Hard Gate v1.0

Date: 2026-09-09
Execution: local Python, deterministic seed 20260909.

## Objective

Test whether the relational structure itself can select a unique composition algebra from observable behavior, rather than the algebra being imposed by convention.

Candidate algebras:

- max-min: `(A∘B)_ij = max_k min(A_ik,B_kj)`;
- min-plus: `(A∘B)_ij = min_k(A_ik+B_kj)`;
- sum-product: `(A∘B)_ij = Σ_k A_ik B_kj`.

All three operate on the same finite weighted relational carrier.

## H1 — Structure-only observable cannot select the algebra

Dense positive 5×5 relation matrices were generated. For each pair `(A,B)`, the three candidate compositions were calculated. The observable was restricted to binary support (`nonzero / zero`).

Trials: 500.

Result: **500/500 support observables identical across all three algebras.**

Conclusion: support/reachability alone cannot identify the composition algebra in this model class.

## H2 — Full numerical composition can discriminate algebras

For 300 independent 5×5 triples, a held-out composition was generated under each candidate algebra. Each candidate was then scored against the generated numerical observation by relative Frobenius error.

Recovery accuracy:

| Generating algebra | Correctly selected |
|---|---:|
| max-min | 300/300 (100%) |
| min-plus | 300/300 (100%) |
| sum-product | 300/300 (100%) |

Mean relative error for the correct algebra was exactly 0 by construction. Mean error for incorrect models remained nonzero:

- max-min data: min-plus ≈ 0.348; sum-product ≈ 20.765;
- min-plus data: max-min ≈ 0.319; sum-product ≈ 19.058;
- sum-product data: max-min ≈ 0.954; min-plus ≈ 0.951.

Result: **PASS for empirical model selection when the composition output itself is observable.**

## H3 — This does not make the algebra intrinsic

The same relational carrier admits all three algebras. H2 succeeds because the observation includes the numerical result generated by one declared composition law. The data therefore identify the generating model, not a law forced by the carrier alone.

Result: **CONFIRMED.**

## H4 — Distinguishing observable is the missing bridge

There are two regimes:

1. Structure-only observation: candidate algebras remain observationally equivalent in the dense-support test.
2. Algebra-sensitive numerical observation: candidate algebras become empirically distinguishable.

Therefore algebra selection requires an observable whose transformation law differs between candidates.

Result: **PASS.**

## H5 — No unique algebra follows from formal closure

Associativity, identity/covariance and composability are shared by multiple valid algebras. These properties therefore cannot by themselves select max-min, min-plus, sum-product, probability normalization, or another algebra.

Result: **FAIL** for the claim that formal structural closure uniquely determines the algebra.

## Adversarial conclusion

The strongest surviving distinction is:

`carrier/relations → admissible algebra family → observable → model discrimination`.

A relational structure does not contain a unique numerical composition law merely because several algebras can be implemented on it.

However, once an independent observable is available, competing algebras can be experimentally distinguished and one can be rejected in favor of another for that model class.

This is an important upgrade: **algebra need not be chosen arbitrarily forever; it can become an empirically testable hypothesis.** What is not justified is promoting the winning algebra to a universal consequence of relation alone.

## Promotion decision

PROMOTE the distinction between:

- carrier/relational structure;
- declared algebra;
- algebra-sensitive observable;
- empirical model selection.

The language should permit multiple algebra implementations without conflating them.

### FUNDAMENT

DO NOT promote any one algebra as fundamental from this test.

A future fundamental claim requires an independently specified physical observable and repeated cross-domain discrimination against competing algebras.

## Strongest current statement

`structure alone does not select algebra; observable transformation behavior can select among candidate algebras.`

This is stronger than saying simply that algebra is a convention, and safer than saying that algebra is derived from structure.

## Next hard gate

Move from synthetic matrix outputs to an observation model that is external to the candidate algebra. The decisive test is whether a physical or independently measured observable can discriminate competing Ω-Math algebras without embedding the answer into the measurement definition.
