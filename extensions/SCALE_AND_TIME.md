# Ω-Math Extension — Scale and Time

**Status:** Mathematical boundary result
**Source lineage:** OMEGA-TIME-006

## Three notions

1. **Ordinal succession** — an ordered sequence of transitions.
2. **Dimensionless interval** — a count or ratio derived from the trajectory.
3. **Physical duration** — a quantity carrying an operational dimensional scale.

These notions must not be identified.

## Scale ambiguity

Consider a dimensionless autonomous system

`x_(n+1) = F(x_n)`.

The iteration index n supplies order but no physical unit. Any dimensionless temporal coordinate derived from the trajectory remains dimensionless.

A rescaling

`q → c q`, `c > 0`,

preserves ordering and purely dimensionless relations unless an independent scale-setting invariant is introduced.

## Boundary theorem for this model class

If the primitive state space, transition law and observables are dimensionless, then a unique physical duration cannot be derived from those ingredients alone.

An additional structure is required: for example a physical frequency, action/energy scale, causal propagation constraint, geometric scale or another independently dimensional invariant.

## Ω rule

`transition count ≠ physical duration`.

`internal order ≠ physical time`.

This is a boundary statement, not a proof that physical time can never emerge in a richer theory.
