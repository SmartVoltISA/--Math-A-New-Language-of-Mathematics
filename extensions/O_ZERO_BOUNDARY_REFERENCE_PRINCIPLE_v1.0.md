# Ω-0 — Boundary / Reference Principle v1.1

## Status

**FOUNDATIONAL HYPOTHESIS / CANONICAL RESEARCH PRINCIPLE**

This document records the Ω interpretation of `0` as a boundary/reference condition and extends it to the internal/external distinction. It does **not** change the typed core domains of Ω-Math.

## 1. Core distinction

Ω-Math keeps the following typed domains unchanged:

`EntityState = {0,1}`

`RelationState = {−1,+1}`

The value `0` is **not** promoted to a third `RelationState` value.

Therefore:

`absence of relation ≠ RelationState(0)`

A missing relation is absence of an element of the relation domain, not a zero-valued relation.

## 2. Ω-0 as boundary / reference

Within the broader Ω research program, `0` is treated as a candidate **boundary / neutral reference / transition point** between opposing states or directions.

```text
        −1        |        +1
                  0
              boundary
              reference
```

The `0` point is not a third opponent. It is the boundary or reference against which deviation toward `−1` or `+1` can be described.

## 3. Front of interaction

When two opposing entities, tendencies, or relational directions interact, `0` may be interpreted as the **front of interaction** (frontier of the current balance), rather than as an additional participant.

```text
A  ←──────  0  ──────→  B
           ↑
       interaction
          front
```

The terms *battle*, *competition*, or *struggle* are interpretations for particular dynamical models. They are not primitives of Ω-Math.

## 4. Internal / external boundary

The same boundary concept extends to the distinction between an internal domain and an external domain.

```text
                 EXTERNAL
                    ↓
          ───────── 0 ─────────
                    ↑
                 INTERNAL
```

The selected boundary provides the reference relative to which *inside* and *outside* are defined. Thus internal and external are relational descriptions with respect to the boundary.

When an external process interacts with an internal system, `0` may represent the current **interaction frontier** at which external influence and internal response meet.

```text
EXTERNAL  →  [ 0 ]  →  INTERNAL
               ↑
          interaction front
```

The frontier may transmit, reject, transform, or reflect an interaction; the mechanism must be declared by the model.

For competitive models, the frontier may be interpreted as the location where external influence and internal response meet in a struggle. This remains an interpretation, not a primitive.

## 5. Reference point and deviation

If `0` is selected as a reference, then `−1` and `+1` represent opposite directed deviations from that reference.

The general conceptual pattern is:

`reference → deviation → interaction → change → new reference`

This connects directly to the Ω research principle:

`boundary → deviation → check → feedback → correction → new stable state`

## 6. Dynamic boundary, path and time

For a time-indexed system, the boundary/reference can itself change:

```text
t₀        t₁        t₂        t₃
 |         |         |         |
 0₀  →     0₁  →     0₂  →     0₃
```

The sequence is a candidate representation of the changing frontier.

A dynamic internal/external system can therefore be represented conceptually as:

`external influence → boundary interaction → internal response → boundary change → new configuration`

This motivates the research statement:

> **A path can be understood dynamically as a time-ordered sequence of changing boundary/front states produced by transformations or interactions.**

A stronger phrase, **“path is struggle through time”**, is retained as an interpretive hypothesis for systems whose transformation mechanism is competitive/oppositional. It is not adopted as the universal definition of `PATH`.

## 7. Separation of layers

The following distinctions are mandatory:

- `0 as boundary/reference` ≠ `0 as relation value`
- `absence` ≠ `0`
- `boundary` ≠ `entity`
- `boundary` ≠ `relation`
- `internal/external` ≠ `EntityState`
- `path` ≠ `scalar`
- `path` ≠ automatically `struggle`
- temporal ordering ≠ physical duration
- interaction ≠ automatically causality

## 8. Why this does not change RelationState

The formal language needs to distinguish two questions:

1. **Does a relation exist, and if so, what relational sign does it have?**
2. **Where is the reference/boundary between opposing directions or between internal and external domains?**

`RelationState = {−1,+1}` answers the first question for an existing relation.

Ω-0 addresses the second question at a higher conceptual/dynamical layer.

Adding `0` to `RelationState` would collapse these distinct meanings and would incorrectly encode relation absence or boundary state as a third relation sign.

## 9. Research status

This principle is a formalized continuation of the Ω-Lab line of investigation into zero, boundary, balance, transition, interaction and internal/external organization. It is **not evidence of a universal physical law**.

Future experiments may test whether measurable systems exhibit a useful boundary variable whose evolution predicts transitions, stabilization, adaptation, memory, or other observables.

## 10. Canonical statement

> **Ω-0 Boundary / Reference Principle:** `0` may serve as a boundary, neutral reference, or interaction frontier between opposing states and as the frontier separating and connecting internal and external domains. It is not a third relational state and does not encode relation absence. External influence and internal response may meet at this frontier. In a dynamical interpretation, the time-ordered evolution of such a frontier provides a candidate basis for describing a path; “struggle through time” is a model-specific interpretation, not a primitive definition.
