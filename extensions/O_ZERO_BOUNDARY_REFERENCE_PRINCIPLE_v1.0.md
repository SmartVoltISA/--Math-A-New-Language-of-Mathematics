# Ω-0 — Boundary / Reference Principle v1.0

## Status

**FOUNDATIONAL HYPOTHESIS / CANONICAL RESEARCH PRINCIPLE**

This document records the Ω interpretation of `0` as a boundary/reference condition. It does **not** change the typed core domains of Ω-Math.

## 1. Core distinction

Ω-Math keeps the following typed domains unchanged:

`EntityState = {0,1}`

`RelationState = {−1,+1}`

The value `0` is **not** promoted to a third `RelationState` value.

Therefore:

`absence of relation ≠ RelationState(0)`

A missing relation is absence of an element of the relation domain, not a zero-valued relation.

## 2. Ω-0 as boundary

Within the broader Ω research program, `0` is treated as a candidate **boundary / neutral reference / transition point** between opposing states or directions.

Conceptual form:

```text
        −1        |        +1
                  0
              boundary
              reference
```

The `0` point is not a third opponent. It is the boundary or reference against which deviation toward `−1` or `+1` can be described.

## 3. Front of interaction

When two opposing entities, tendencies, or relational directions interact, `0` may be interpreted as the **front of interaction** (frontier of the current balance), rather than as an additional participant.

```text
A  ←──────  0  ──────→  B
           ↑
       interaction
          front
```

The terms *battle*, *competition*, or *struggle* are interpretations for particular dynamical models. They are not primitives of Ω-Math.

## 4. Reference point and deviation

If `0` is selected as a reference, then `−1` and `+1` represent opposite directed deviations from that reference.

The general conceptual pattern is:

`reference → deviation → interaction → change → new reference`

This connects directly to the Ω research principle:

`boundary → deviation → check → feedback → correction → new stable state`

## 5. Dynamic interpretation

For a time-indexed system, the boundary/reference can itself change:

```text
t₀        t₁        t₂        t₃
 |         |         |         |
 0₀  →     0₁  →     0₂  →     0₃
```

The sequence is a candidate representation of the changing frontier.

This motivates the research statement:

> **A path can be understood dynamically as a time-ordered sequence of boundary/front states produced by transformations or interactions.**

A stronger phrase, **“path is struggle through time”**, is retained as an interpretive hypothesis for systems whose transformation mechanism is competitive/oppositional. It is not adopted as the universal definition of `PATH`.

## 6. Separation of layers

The following distinctions are mandatory:

- `0 as boundary/reference` ≠ `0 as relation value`
- `absence` ≠ `0`
- `boundary` ≠ `entity`
- `boundary` ≠ `relation`
- `path` ≠ `scalar`
- `path` ≠ automatically `struggle`
- temporal ordering ≠ physical duration
- interaction ≠ automatically causality

## 7. Why this does not change RelationState

The formal language needs to distinguish two questions:

1. **Does a relation exist, and if so, what relational sign does it have?**
2. **Where is the reference/boundary between opposing directions?**

`RelationState = {−1,+1}` answers the first question for an existing relation.

Ω-0 addresses the second question at a higher conceptual/dynamical layer.

Adding `0` to `RelationState` would collapse these distinct meanings and would incorrectly encode relation absence or boundary state as a third relation sign.

## 8. Research status

This principle is a formalized continuation of the Ω-Lab line of investigation into zero, boundary, balance, transition and interaction. It is **not evidence of a universal physical law**.

Future experiments may test whether measurable systems exhibit a useful boundary variable whose evolution predicts transitions, stabilization, memory, or other observables.

## 9. Canonical statement

> **Ω-0 Boundary / Reference Principle:** `0` may serve as a boundary, neutral reference, or interaction frontier between opposing states. It is not a third relational state and does not encode relation absence. In a dynamical interpretation, the time-ordered evolution of such a frontier provides a candidate basis for describing a path; “struggle through time” is a model-specific interpretation, not a primitive definition.

**Status: CANONICAL RESEARCH PRINCIPLE / v1.0**
