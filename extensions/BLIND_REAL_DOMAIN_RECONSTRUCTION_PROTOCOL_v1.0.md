# Ω-Math — Blind Real-Domain Reconstruction Protocol v1.0

Date: 2026-09-16
Status: PROTOCOL LOCKED / PRE-REVEAL

## Objective

Test whether the Ω-Math structural kernel can recover common relational architecture from real reference data when domain names, physical units, constitutive equations and parameter meanings are withheld.

Target kernel:

`STATE + RELATION + DISTINCTION + CONSTRAINT + TRANSITION`

The experiment must distinguish structural recovery from accidental recovery of a known domain equation.

## Source families

Use independently curated reference data. Initial candidates include NIST reference data for thermal conductivity, viscosity, electrical resistivity and fluid thermophysical properties. NIST states that its Standard Reference Data are critically evaluated; REFPROP contains evaluated thermophysical models and experimental-data-based correlations. These sources are suitable as provenance-controlled reference material, but their published physical labels must be hidden during the blind phase.

## Blind representation

For each dataset construct a neutral schema:

```text
STATE_A
STATE_B
RELATION
DISTINCTION
CONSTRAINTS
OBSERVED_RESPONSE
```

During reconstruction, hide:

- domain name;
- physical variable names;
- units and dimensional symbols;
- material/substance identity;
- textbook constitutive equations;
- published parameter names;
- source-specific terminology.

Retain numerical observations, ordering, declared measurement uncertainty where available, and provenance identifiers that do not reveal the domain.

## Required controls

### Positive control

A dataset whose structural response is known to admit a low-complexity relational representation.

### Negative control A — permutation

Break the pairing between distinction and response while preserving marginal distributions. Structural reconstruction should degrade.

### Negative control B — coefficient scramble

Preserve the structural input distribution but independently scramble constitutive coefficients between samples/domains. A valid method must not manufacture a universal coefficient.

### Negative control C — nonlinear adversary

Provide a response generated by a nonlinear law while preserving the same state/relation/difference schema. The method must be allowed to reject a universal linear response.

## Frozen outputs before reveal

The reconstruction system must record before domain labels are revealed:

1. inferred state variables;
2. inferred relation topology;
3. candidate distinction/drive;
4. candidate constraint set;
5. response architecture;
6. candidate invariants;
7. residuals/error metrics;
8. rejected models;
9. uncertainty;
10. information that could not be identified.

## Falsification rules

A reconstruction is INVALID if:

- physical variable names leak into the neutral schema;
- units determine the candidate operator directly;
- a target-domain equation is encoded in preprocessing;
- the answer is selected by matching against a library of known formulas;
- coefficients are treated as universal merely because several datasets fit the same form.

A reconstruction is STRUCTURAL-PASS only if the common form is obtained before reveal and survives the negative controls.

## Domain-reveal phase

After the blind record is frozen, reveal the original domains and compare:

`blind structure ↔ actual physical interpretation`.

The reveal may explain a recovered connector, but may not retroactively modify the frozen blind result.

## Decision gates

| Gate | Requirement |
|---|---|
| R1 | provenance locked |
| R2 | neutral schema locked |
| R3 | labels/units withheld |
| R4 | structural reconstruction frozen |
| R5 | negative controls executed |
| R6 | domain reveal performed after freeze |
| R7 | independent replication |

No new Ω-Math primitive may be promoted from this experiment alone.

## Current status

Protocol locked. Data ingestion and neutralization are the next executable stage. The experiment is designed to test the boundary already established between STRUCTURAL CLOSURE and DOMAIN CLOSURE, not to assume a universal physical law in advance.
