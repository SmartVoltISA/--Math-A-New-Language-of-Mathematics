# Ω-Math Extension — Relational Circulation

**Status:** Mathematical extension / structural vocabulary

## Definitions

A directed cycle is a closed path whose ordered relations return to the starting entity.

A circulation variable records oriented accumulation around such a cycle. Its sign depends on the declared orientation convention.

A loop introduces feedback and an alternative route between states. It therefore changes the transition structure relative to an open chain with the same nodes and local edge count.

## Operator connection

For linear relational dynamics, an oriented cycle naturally produces a skew component of the interaction operator. In conservative models this component contributes imaginary spectral modes rather than purely relaxing modes.

## Topological distinction

- open chain: no closed circulation path;
- directed cycle: one closed oriented route;
- multiple cycles: competing or coupled circulation modes;
- graph with cuts: circulation can be blocked or redirected.

## Boundary

Circulation is a mathematical property of an oriented graph/dynamical model. It is not automatically physical fluid circulation, electromagnetic circulation, vorticity or energy flow.

## Research use

The concept should be used to connect graph topology, orientation, feedback and spectral structure while keeping physical interpretation separate.
