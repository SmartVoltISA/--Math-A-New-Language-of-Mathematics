## Coordinate-context rule

A measured value is meaningful only together with its declared context:

```text
WHAT is measured
    ↓
IN WHICH dimension / plane / axis
    ↓
FROM WHICH reference / coordinate frame
    ↓
AT WHICH position / state
    ↓
AT WHICH time / index
    ↓
RESULT
```

A projection is an observation of a system in a specified context, not automatically the whole system.

## Cross-scale hypothesis

Different systems may exhibit analogous structural invariants even when their physical mechanisms differ. Candidate comparison classes include molecular structures, astrophysical systems, networks, oscillatory processes, and biological life histories.

The hypothesis is **not** that these systems are physically identical. The test is whether a structural invariant survives changes of scale, coordinate frame, projection, and physical mechanism.

## Mandatory safeguards

- `0 as boundary/reference` ≠ `0 as relation value`
- absence ≠ `0`
- projection ≠ whole system
- mathematical multidimensionality ≠ proof of a specific physical cosmology
- structural analogy ≠ physical identity
- visual similarity ≠ invariant
- time index ≠ automatically physical duration

## Canonical research question

> **Which structural invariants remain when the same abstract configuration is examined in different dimensions, coordinate contexts, scales, and physical mechanisms?**

This document is a frozen reference schema. New work should extend, test, or falsify it rather than silently redefining it.
