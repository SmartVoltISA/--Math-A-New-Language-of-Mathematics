# Ω-Math v0.1 — Research Map

This document connects the new language to work already performed in Ω-Lab and prevents repeated research from being mistaken for new discoveries.

## 1. Relation-first foundation

Existing Ω-Lab work already treats relations as an experimental object and explicitly asks whether a relation can be recovered from observable changes in states.

The current Ω-Math foundation makes this precise by separating:

`entity state = {0,1}`

from:

`relation state = {−1,+1}`.

The earlier Ω-Lab documentation deliberately warned that graph edges, forces, fields, energy and physical interactions must not automatically be identified with the abstract notion of relation. fileciteturn5file0

## 2. Internal order and time

Ω-0 tested whether an updating internal trace can create distinguishable before/after states without explicitly supplying a physical time coordinate.

Reported minimal pattern:

`ACT → TRACE → UPDATE`

The result is useful for Ω-Math because it supplies an empirical predecessor for the concepts:

`state → retained state → transition → internal order`.

It does not establish a theory of physical time. fileciteturn10file0

## 3. Memory

Ω-MEM provides a direct predecessor for the Ω-Math memory definition:

`recording ≠ memory`

A useful working criterion is that retained state must be capable of changing later behavior or comparison.

Ω-MEM-4R also demonstrates why memory representations must be tested process by process. The reported results supported matched representations for several structured generators but exposed Thue-Morse as a critical counterexample. fileciteturn11file0

Therefore Ω-Math must not claim a universal “memory = S bits” law or any universal minimal memory architecture.

## 4. Information and organization

Ω-INF studies whether changing organization while preserving the same elements produces measurable structural differences.

This maps directly to the Ω-Math distinction:

`composition ≠ organization`.

The research question is important because a relation-first language must be sensitive to organization, not merely to the inventory of symbols.

## 5. Internal dynamics

Ω-B experiments investigate whether specified internal dynamics can produce statistically distinguishable structure relative to controls.

This maps to:

`transition rule → evolving relation configuration → emergent structure`.

The existing experimental policy requires controls, negative results and explicit execution status. Ω-Math inherits that standard. fileciteturn9file0

## 6. Structural quantities

Previous Ω structural work investigated:

- edge count;
- degree thresholds;
- cycles and β₁;
- vertex and edge connectivity;
- independent paths;
- stability/lifetime;
- structural speed;
- build/decay ratios.

These should be treated as candidate derived observables of Ω-structures rather than primitive quantities.

A key methodological lesson is that one structural metric should not be promoted to a universal law merely because it correlated with one target in one experiment.

## 7. Repetition audit

Before creating a new Ω-Math concept, search existing Ω repositories for an equivalent operation or result.

Potential duplicates to check first:

`state`
`difference`
`relation`
`memory`
`history`
`transition`
`cycle`
`connectivity`
`stability`
`independent paths`
`emergence`
`self-reference`

If an old concept already exists, Ω-Math should either:

1. adopt it and record provenance;
2. refine it and explain the change;
3. reject it and explain why.

Do not create a new name merely for an old object.

## 8. Current synthesis

The strongest existing chain is currently:

`distinguishability`
`→ relation`
`→ configuration`
`→ structure`
`→ transition`
`→ retained state`
`→ functional memory`
`→ prediction`
`→ feedback`
`→ self-model candidate`
`→ higher-level structure`.

Only the first parts are formalized in Ω-Math v0.1. The later arrows remain research hypotheses.

## 9. What is already established versus open

### Already defined or operationally explored

- binary entity state representation;
- signed relation representation;
- structural graph observables;
- internal state transitions;
- functional-memory criteria;
- experimental distinction between data, observation and hypothesis;
- explicit use of controls and negative results.

### Still open

- a unique Ω relation-composition law;
- a primitive identity relation;
- universal path algebra;
- derivation of metric geometry;
- derivation of physical time;
- a universal emergence criterion;
- a validated self-model criterion;
- a scientific theory of consciousness;
- a physical theory derived from Ω primitives.

## 10. Rule for future work

Every new Ω-Math result must answer:

`What was already known?`

`What is newly defined?`

`What is newly derived?`

`What was actually executed?`

`What control could break it?`

`What existing mathematics gives the same result?`

This is how the language becomes a cumulative mathematical research program rather than a collection of renamed ideas.
