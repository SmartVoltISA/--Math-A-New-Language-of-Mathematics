# Ω-Math — Relational Geometry 001

## Status

`DERIVED CONSTRUCTION / EXECUTED FINITE TEST / GLOBAL NOVELTY NOT CLAIMED`

This document introduces the first Ω-specific geometric construction that removes the fixed relation-slot assumption from `GEOMETRY_FROM_TRANSFORMATION.md`.

The construction is new as an Ω-Math layer. It is **not** claimed here to be new mathematics globally. Closely related constructions exist in graph edit distance, quotient metrics, configuration spaces and orbit metrics. The Ω contribution is the explicit derivation from the typed relational language and its anti-coercion rules.

## 1. Typed relational configuration

A finite Ω configuration is

`C = (E, D_R, R)`

where:

- `E` is a finite set of entities;
- every entity has state in `{0,1}`;
- `D_R ⊆ E × E` is the declared relation domain;
- `R` is a partial map from `D_R` to `{−1,+1}`.

Absence is not a relation value.

## 2. Primitive edit events

For a declared correspondence between two configurations, three elementary edit classes are admitted:

1. `ENTITY_FLIP(e)` — changes `0 ↔ 1`;
2. `REL_ADD(x,y,s)` — adds an absent relation with sign `s`;
3. `REL_REMOVE(x,y)` — removes a present relation;
4. `REL_FLIP(x,y)` — changes `−1 ↔ +1`.

Each event has a declared non-negative cost.

The default unit system is

`c(ENTITY_FLIP)=1`

`c(REL_ADD)=1`

`c(REL_REMOVE)=1`

`c(REL_FLIP)=1`.

No physical energy meaning is assigned to these costs.

## 3. Relational edit path

A transformation path is a finite sequence of admissible edit events

`P = (u₁,u₂,...,u_k)`

such that applying the events transforms `C` into `C'`.

Its cost is additive:

`c(P)=Σ c(uᵢ)`.

The directed structural edit distance is

`d(C,C') = inf { c(P) : P : C → C' }`.

For finite configurations with unit costs, the infimum is a minimum.

## 4. Why this is different from the previous baseline

The previous metric baseline assumed a fixed vector of relation slots. That construction reproduces a Hamming metric.

The present construction permits the relation topology itself to change:

`absence → relation`

`relation → absence`

as well as entity-state changes and sign changes.

Therefore geometry is now generated by **structural change**, not only by changing values inside a fixed encoding.

## 5. Label-independent relational distance

Labels are representation unless explicitly declared physical.

For configurations with equal numbers of entities, let `Iso(E,E')` be the set of bijections between entity sets. Each bijection induces a relabeling of the configuration.

Define

`d_Ω([C],[C']) = min_{φ ∈ Iso(E,E')} d(C, φ(C'))`.

Here `[C]` denotes the structural orbit of `C` under allowed relabelings.

This makes the geometric quantity representation-invariant under the declared relabeling group.

## 6. Theorem: quotient distance

Assume:

1. elementary edit costs are non-negative;
2. edit paths compose;
3. relabelings preserve admissible edit types and costs;
4. configurations compared by `d_Ω` have the same entity cardinality.

Then `d_Ω` satisfies:

- non-negativity;
- symmetry when every edit has an equal-cost inverse;
- triangle inequality;
- invariance under simultaneous relabeling.

It is therefore a metric on structural orbits when zero distance occurs only for the same orbit.

### Proof sketch

Non-negativity follows from non-negative event costs.

Composition of edit paths gives

`d(C₁,C₃) ≤ d(C₁,C₂)+d(C₂,C₃)`.

Taking the minimum over admissible relabelings preserves the triangle inequality because relabelings compose.

If every edit has an equal-cost inverse, reversing an optimal path gives symmetry.

Zero distance identifies exactly those configurations related by zero-cost transformations; under unit-cost edits this is precisely the same structural orbit.

Thus the quotient is a metric space under the stated assumptions.

## 7. Directed case

If an edit and its inverse have different costs, or one direction is forbidden, the natural object is

`d_Ω(C,C') ≠ d_Ω(C',C)`.

This is a directed distance rather than a metric.

Ω-Math retains this asymmetry instead of forcing a symmetric geometry.

## 8. Relation to behavioral equivalence

Structural distance and behavioral equivalence are distinct.

It is possible that

`d_Ω(C,C') > 0`

while

`C ≈ᵦ,h C'`.

This means structural difference exists but is invisible to the declared task and horizon.

Conversely, two configurations with the same aggregate statistics can have positive structural distance and different behavior.

Therefore:

`structural distance ≠ behavioral difference`.

A reduction may collapse structural distance only when the declared task's behavior is preserved.

## 9. New Ω object: relational geometry signature

A scalar distance can still hide structure. Ω therefore defines a derived signature

`Γ_h(C) = { d_Ω(C,C') : C' is behaviorally distinguishable from C within horizon h }`.

The signature may be represented as an ordered spectrum, histogram or exact multiset depending on the experiment.

This is not declared a universal invariant. It is a derived observable of a chosen transformation family and behavioral horizon.

The purpose is to preserve more information than a single distance while remaining derived from the same typed transformation system.

## 10. Falsification targets

The construction is rejected for a chosen application if:

- results depend on arbitrary labels after quotienting;
- zero-cost non-equivalent configurations occur;
- triangle inequality fails despite reversible additive costs;
- changing the allowed edit basis changes conclusions without being reported;
- behavioral conclusions are inferred from distance alone;
- the construction requires hidden spatial coordinates.

## 11. Mathematical status

What has been established:

`typed configuration → admissible edit algebra → path cost → structural distance → quotient/orbit distance`.

What has **not** been established:

`structural distance → physical space`.

The latter remains an empirical/physical hypothesis and requires an independent bridge.

## Core result

Ω-Math now has a geometry construction in which the geometry is induced by the **cost of changing relational organization itself**, including relation creation and destruction.

This is the first v0.5 candidate for a general Ω relational geometry.
