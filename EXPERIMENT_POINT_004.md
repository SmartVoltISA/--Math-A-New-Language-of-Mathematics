# Ω-Math Experiment POINT-004 — Does a Boundary Emerge from Relational Closure?

## Question

Can a Point-like regime be produced by relational dynamics without defining a boundary in advance as a physical object?

## Minimal model

Use a finite directed system of entities with two classes of relations:

- internal relations between entities already belonging to a candidate cluster;
- external relations connecting the cluster to the remainder of the system.

The candidate cluster is selected from relational connectivity, while the boundary is measured afterward from the cut between the cluster and its complement.

This avoids defining the boundary as a primitive outcome.

## Control parameter

At each step, let a closure process increase the preference for relations that remain inside the currently coherent cluster while retaining a nonzero probability of external relation creation.

Measure:

`C_in = R_II / R_total`

`C_out = R_external / R_total`

where `R_external` contains relations crossing the measured cluster boundary.

## Expected signatures

A Point-like trajectory would show:

`C_in ↑`

`C_out ↓`

while the internal graph remains nontrivial.

A stronger result would be the spontaneous appearance of a stable cut/boundary whose location is not prescribed by the initial model.

## Critical control

Compare against a null model with the same number of entities and total relations but randomized endpoint selection. If the same closure/boundary behavior appears with comparable frequency, relational closure alone is insufficient as an explanation.

## Information test

Apply two observation maps:

`O_internal` — distinguishes internal configurations;

`O_boundary` — records only the state available across the measured boundary.

Test whether there are pairs `x,y` for which:

`O_internal(x) ≠ O_internal(y)`

but

`O_boundary(x) = O_boundary(y)`.

If so, the experiment demonstrates compression of external distinguishability without proving destruction of internal information.

## Energy test

Not performed in Ω-Math v0.1 because energy is not yet a primitive or derived quantity. Any future energy/flux test must use an independently defined physical mapping.

## Interpretation rules

A successful observation would establish only that relational dynamics can generate a Point-like organizational regime in the model.

It would **not** establish a black hole, gravity, entropy-area law, or physical reality.

## Status

`DESIGN / OPEN`

No empirical result is claimed until the model is executed and compared with controls.
